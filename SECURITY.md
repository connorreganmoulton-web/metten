# Security policy

Metten is in early development and is not available for trading or public release. Security protections and release readiness have not been fully verified.

## Report a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/connorreganmoulton-web/metten/security/advisories/new) to contact the maintainers. Include a description, affected version or commit, and safe reproduction steps. Do not include real credentials, account data, or private trading records. Please do not disclose exploitable details in a public issue.

Maintainers can use the private report to coordinate investigation and disclosure. Please allow time for a fix before publishing details.
