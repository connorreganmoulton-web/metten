# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Brief is ready for an agent, subject to dependencies and action permissions |
| ready-for-human | ready-for-human | Human decision or action required |
| wontfix | wontfix | Will not be actioned |

Apply these exact labels when a skill names a role. Labels never override blockers, credential permissions or real-money approval requirements.
