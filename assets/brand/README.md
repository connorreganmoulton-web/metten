# Metten digital identity

This is the accepted Metten digital identity v1.0. The editable master is [source/metten-master.svg](source/metten-master.svg); use the prepared [SVG](exports/svg/), [PNG](exports/png/), and [PDF](exports/pdf/) exports for finished artwork. See the [brand guide](brand-guide.pdf) and [digital specifications](specifications.json) for usage and sizes.

- **Primary** uses ink and cobalt on light backgrounds; **reversed** uses chalk and cobalt on dark backgrounds. Ink and chalk variants are single-color alternatives.
- Use the A symbol for square canvases of 48 CSS pixels or larger, B small for 24–47, and B micro for 16–23. The full lockup requires at least 240 pixels of visible artwork; the wordmark alone requires 160 pixels.
- Preserve the outlined wordmark, spacing and clear space described in the guide. The colors are cobalt `#304FFF`, ink `#15171C`, and chalk `#F1EFE8`. Inter is the selected interface typeface.
- Avoid Bitcoin imagery, currency symbols, 15-minute clocks, taglines, and performance or readiness claims.

The original round-31 digital kit supplies the master, exports, guide, specifications, and license records here. The logo lettering is outlined from Clash Grotesk Bold; the font software is not included. The [font source record](licenses/font-source.json), [Clash license](licenses/Clash-Grotesk-FFL.txt), and [Inter license](licenses/Inter-OFL.txt) are provided for provenance. Inter font software is not included here. These records do not establish trademark clearance or expand the project's software license.

The kit's prior verification covered digital renders and editing; physical device, print, and platform-specific use remain unverified. Earlier explorations and illustrative mockups are not current artwork.
